# 🐦 Adenola Tech Live Code Editor

A lightweight, browser-based live code editor built with raw HTML, CSS, and JavaScript. This tool provides web developers with a real-time split-screen workspace to write frontend code and instantly view the visual rendering.

---

## ✨ Features

* **Real-time Live Preview:** See your visual modifications update instantly in the execution window as you type.
* **Developer UI Layout:** Designed with a dark-mode developer canvas panel alongside a clean, crisp output sandbox window.
* **Zero Dependencies:** Built entirely with native web technologies—no frameworks, compilation steps, or installations required.

---

## 🛠️ Built With

* **HTML5:** Structures the document views, editor workspace blocks, and the sandbox preview iframe.
* **CSS3:** Flexbox grid properties and styling layout rules optimized for complete viewport fitting.
* **JavaScript (ES6):** Captures typing event listeners to dynamically compile code strings directly into the frame DOM.

---

## 🚀 Getting Started

Getting your personal live developer window running locally takes less than a minute.

### 1. Setup Your Files
Ensure your project folder contains these three primary source code files:
* `index.html`
* `style.css`
* `script.js`

### 2. Launching the App
Simply double-click the `index.html` file to automatically execute and launch the development dashboard directly inside your default web browser (Chrome, Firefox, Safari, Edge, etc.).
